Status

Currently, NewsCache is in its beta testing phase. Yes, there is still a problem that needs to be fixed (see below). Unfortunately, I do not have as much time to work on NewsCache as I would like to have (any volunteers?).

The latest version is 0.99.19 and it includes the following fixes (Thanks to Herbert Straub <herbert.straub at emb.magwien.gv.at> for the fixes and the new release):

  • Minor compile fixes for some platforms (missing includes)
  • Post in cascaded NewsCache Configuration now working
  • list active wildmat fixed
  • Performance fixes for NewsCacheClean

If you have fixes/questions, please post them to the Download

The latest Version is 0.99.19. You can download NewsCache using HTTP.

When compiling NewsCache be aware to use a recent C++ compiler. gcc-2.7.2 does not work on any platform! I have even found bugs in the version for intel platforms. Currently, I a am using gcc-2.95.2.
