ConfigVersion

This option specifies the version of the configuration file. The version of the configuration file's current syntax is 1. When the News Cache starts up it checks this variable to see whether the syntax of the configuration file matches the syntax expected by the current News Cache.

If you specify this option you will get a warning message when upgrading the News Cache to a version with a new syntax of the configuration file. 

ConfigVersion 1
