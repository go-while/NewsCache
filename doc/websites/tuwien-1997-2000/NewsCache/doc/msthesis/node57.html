Setting Up the Target Directory

In the News Cache directory, issue the command make target. This sets up a target directory for your machine. If you do not have the uname command installed or want to use another directory for your target, you may specify this using the TARGET environment variable.

After you have created the target directory, you should change into the directory targets and then into your target directory. This directory is a ``copy'' of the News Cache directory. To reduce the required disk space, all non-configuration files are just links to the appropriate file in the News Cache source directory.
