NewsCache News

  • 2008-04-12: Christof Meerwald create a IPv6 support patch, see the Feature Request Page for details
  • 2006-08-17: Arnold Schiller created a modified NewsCache Version with ldap authentication against the open-mews-network.org server. For details see the Feature Request Page
  • 2006-08-17: The RPM for NewsCache is included in the fedoraproject.org collection! If you have added the yum repository, the installation starts with yum install newscache.
  • 2004-11-03: 1.2rc Patch 1; configuration error: specifing --prefix without --sysconfdir; thanks to Mike Harding and Tilman Linneweh for reporting this situation.
  • 2004-10-01: Version 1.2rc6 released.
  • 2004-07-28: LSB Init Script Name Registry: register initscript newscache.
  • 2004-06-22: Correcting nntpcache link. Some of the mailinglist archiv and search features are not working - Alex try to fix it
  • 2004-01-16: 1.1.92: bugfix tin hanger. Mike Harding reported this problem. Updating man pages. See Changelog for details. The status changed from Development to Testing. The major goal is stabilizing the progrom and find bugs. The next stable version would be 1.2.
  • 2004-01-14: Thomas Gschwind has no more time to make further development on NewsCache. He placed a notice and a link to this Project site on his NewsCache master site.
  • 2003-12-11: 1.1.91: client command parse bugfix, reported by Konstantin Nikonenko
  • 2003-10-27: 1.1.90: improved authenticaion model (with PAM), improved documentation, bugfixes.
  • 2003-04-10: uploading newscache 1.1.12 debian package (sid) - not a official package - only for easy testing
  • 2003-04-06: FreeBSD Port by Tilman Linneweh
  • 2003-04-05: 1.1.12: new optimized purge strategie (newscacheclean)
  • 2003-03-23: FreeBSD Port 0.99.22p1 available (Tilman Linneweh)
  • 2003-03-21: RedHat contrib RPM for 0.99.22p1 available (Carles Arjona)
  • 2003-03-18: Bugfix (stable version)! DATE command returns localtime. Thanks to Matthias Andree.
