NewsCache

by Herbert Straub — last modified 2007-03-12 09:31

NewsCache is a free cache server for USENET News.

NewsCache acts to news reading clients like a news server, except that it stores only those articles that have been requested by at least one client. NewsCache targets problems of the current News System like network bandwidth consumption or the IO load caused by news clients.

Author

The original author is Thomas Gschwind. Here you find the original home of NewsCache, the complete documentation and the original Status of the project. Due to serious time constraints, Thomas Gschwind unfortunately have no longer time to work on NewsCache.

History

I collect the patches und create improvments since 2000. I created also the last version 0.99.19 on Thomas Gschwind's Homepage. Now i'm maintaining the NewsCache Project. The goal is to create a new improved stable version of NewsCache. You can find a detailed description of bugfixes, improvments, new functionality in the ChangeLog file. The mailing list (newscache@infosys.tuwien.ac.at) is dead since March 2002. Alex Holden from linuxhacker.org creates a new one in November 2002 (see Mailinglist).
