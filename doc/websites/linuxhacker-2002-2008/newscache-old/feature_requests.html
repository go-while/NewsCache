Feature Requests

This is a collection of feature requests and patches for future releases of NewsCache. If you missing some functionionality send a feature request of better a patch :-).

Pending Patches
  • Konstantin Nikonenko: regular expression patch. Works fine, but i think, there is a litte problem in the server section. More investigation requiered.
  • Arnold Schiller created a modified version of NewsCache with ldap authentication support. I created patch file against 1.2rc6. This enables NewsCache to verify user and password against the open-news-network.org ldap server.
Feature Requests
  • NewsCache should automatically add subscribed newsgroups to the prefetch file by Bill
  • Limit the number of fetched header for a newsgroup to avoid downloading thousends of headers. This could be done by a hard limit (eg 10000 headers) or by date. This request could be checked against Cristof Meerwalds low bandwidth modification (see link page for Cristof's site). Requested by Bill.
