		      NewsCache - nntps (SSL) with stunnel
		      ====================================

							  Author: Herbert Straub
						  e-mail: herbert@linuxhacker.at

Since 1.3.23 NewsCache does TLS for clients itself, and that is the way
to do it now: see TLSListenTo, TLSCertFile and TLSKeyFile in
newscache.conf(5) and the README, and newscache -t for inetd. You don't
need stunnel for it.

The stunnel setup below is only an alternative. Note that NewsCache then
sees every client as coming from stunnel's address (for example
127.0.0.1), so a Client entry for that address lets everybody in.

1) Installing stunnel
---------------------

Install the stunnel package of your system (stunnel 4 or 5).

2) Creating certificate
-----------------------
$> openssl req -new -x509 -days 365 -nodes \
 	-out stunnel.pem -keyout stunnel.pem
Don't forget to move the certificate file to the right place 
(/etc/ssl/certs/stunnel.pem) and to make it readable only for stunnel.

3) Starting newscache
---------------------

Start newscache as usual; it listens on port 119 (ListenTo).

4) Starting stunnel
-------------------

Create /etc/stunnel/nntps.conf:

[nntps]
accept = 563
connect = 119
cert = /etc/ssl/certs/stunnel.pem

and run

stunnel /etc/stunnel/nntps.conf

Add "foreground = yes" and "debug = 7" at the top of the file for a
verbose run that doesn't fork.

5) Ready for nntps!!
